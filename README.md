# Express Trinidad

Sitio oficial de Express para el servicio de mototaxi en Trinidad, Beni, Bolivia.

## Organización

- `index.html`: página principal.
- `assets/css/`: estilos visuales.
- `assets/js/`: interacciones y funciones.
- `assets/images/`: imágenes y logotipos.
- `backups/`: copias de respaldo.

## Publicación

El sitio está preparado para publicarse como página estática. El archivo de entrada es `index.html`.

## Contenido actualizado

- Lanzamiento el 1 de octubre.
- Precio elegido y negociado entre pasajero y conductor.
- 0% de comisión por lanzamiento.
- Botón de pánico y contacto con administración.
- Ubicación compartida y seguimiento del viaje.
- Reconocimiento facial para pasajeros y conductores.
